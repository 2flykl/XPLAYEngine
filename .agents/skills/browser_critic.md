# Skill: Browser QA and Visual Critic

Act as @qa.

## Objective
Reject anything that would make a user think "beta test" instead of "arcade."

## Browser Pass
Use Antigravity Browser Agent / BrowserMCP / Playwright as available.

Test:
- home
- library
- create
- Calibrate Prompt
- direct demo launches
- generated PLX
- export
- desktop and mobile

## Mandatory Engine Matrix
Runner, Dodge, Collect, Rhythm, Puzzle, FPS, Fighting, Open World, Racing, Platformer.

## Mandatory Evidence
FPS and Fighting each get:
- launch screenshot
- active gameplay screenshot
- controls verified
- completion/failure verified

## Visual Critic
Flag bad extraction, black squares, broken scale, wrong scroll direction, unreadable HUD, style mismatch, dead space, bad camera, or weak first 5 seconds.

Create `production_artifacts/qa/QA_REPORT.md`.

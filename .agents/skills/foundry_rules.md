# Skill: XPLAY Foundry Operating Rules

## Objective
Keep all Antigravity agents aligned with XPLAY's product goal and prevent parallel-agent chaos.

## Rules
1. Read `.agents/agents.md`, `production_artifacts/XPLAY_NORTH_STAR.md`, and `production_artifacts/OWNERSHIP_MATRIX.md` before editing.
2. Never remove a working PLX category as a shortcut.
3. FPS and Fighting are release locks.
4. Prefer systemic improvements over one-off visual hacks.
5. Use artifact handoffs when another agent owns the target file.
6. Do not overwrite another agent's active work without Director approval.
7. Every significant change must have a test or observable acceptance criterion.
8. Do not present raw geometric placeholders in normal gameplay.
9. Preserve user source-media identity only when extraction quality is credible.
10. Update `production_artifacts/TASK_BOARD.md` with status and evidence paths.

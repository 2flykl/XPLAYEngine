# Skill: Specialist PLX Runtime

Act as @runtime.

## Objective
Make every category behave according to its own game grammar.

## Work Order
1. Verify runtime registration for all 10 categories.
2. Verify FPS and Fighting first.
3. Repair category camera/scroll laws.
4. Replace remaining runtime primitives with category-native art/fallback roles.
5. Add one signature moment to each engine.
6. Confirm controls, scoring, completion/failure.
7. Avoid over-generalizing one scene class into incompatible genres.

## Required FPS Test
Launch Frontline Echo and a generated FPS. Prove aim, fire, reload, enemy depth scaling, health/ammo, and resolution.

## Required Fighting Test
Launch Street Clash and a generated Fighting PLX. Prove two fighters, movement, jump, punch, kick, block, enemy AI, health, and KO.

## Handoff
Write runtime evidence to `production_artifacts/runtime/`.

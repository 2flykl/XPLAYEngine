XPLAY LIVE GEMINI VISION — CLOUD RUN

1) Keep GEMINI_API_KEY out of the repo.

2) Deploy from repo root:
gcloud run deploy xplay-api --source . --region us-central1 --allow-unauthenticated --set-env-vars GEMINI_VISION_MODEL=gemini-2.5-flash,CORS_ORIGINS=https://2flykl.github.io --set-secrets GEMINI_API_KEY=XPLAY_GEMINI_KEY:latest

3) If needed, create the secret:
echo YOUR_GEMINI_KEY | gcloud secrets create XPLAY_GEMINI_KEY --data-file=-

4) Copy the Cloud Run URL.

5) In GitHub -> Settings -> Secrets and variables -> Actions -> Variables:
Name: XPLAY_API_BASE_URL
Value: https://YOUR-CLOUD-RUN-URL

6) Redeploy Pages.

7) Verify:
https://YOUR-CLOUD-RUN-URL/api/health
https://YOUR-CLOUD-RUN-URL/api/vision/health

8) Hard-refresh:
https://2flykl.github.io/XPLAYEngine/

XPLAY Parsed Packet Style Side Test

This side test starts from the current parsed packet and working source assets. It skips Vision and lets you build multiple style reinterpretations from the same checkpoint.

  1. Copy your OpenAI key into a local .env file.
  2. Run npm install.
  3. Run node server.js.
  4. Open http://localhost:8808.

You can also double-click START-PARSED-STYLE-SIDE-TEST.bat.

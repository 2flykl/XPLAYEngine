XPLAY OpenAI Vision Test Lab

This lab needs a local Node server because it calls the OpenAI API securely from the backend.

  1. Open this folder in VS Code or your repo folder.
  2. Copy .env.example to .env and paste your real OPENAI_API_KEY.
  3. Run npm install.
  4. Run npm run dev.
  5. Open http://localhost:8788.
npm install
npm run dev

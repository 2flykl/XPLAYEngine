# XPLAY Arcade Quality Gates

A build passes only if all gates below pass.

## Gate 1 — Functional Create Flow
- Upload works.
- Analyze button works.
- Adjust / confirm works.
- Review leads to build.
- Build reaches playable output or reports an actionable error.

## Gate 2 — Truthful Analysis
- Screenshot analysis reflects the actual uploaded image.
- Adjustments persist.
- Current build artifacts reflect current input, not previous demos.

## Gate 3 — Library Truthfulness
- Every showcased PLX card looks like gameplay.
- Card visuals align with card title/category.
- No old placeholder or Flux stand-ins unless explicitly intended.

## Gate 4 — Genre Separation
- Runner looks different from Fighting.
- Fighting looks different from FPS.
- Puzzle looks different from Open World.
- Racing looks different from Platformer.

## Gate 5 — Runtime Credibility
- PLXs mount and play.
- No black void / dead canvas.
- No dead controls.
- No endless loading state.

## Gate 6 — Flagship Integrity
- FPS works.
- Fighting works.
- Screenshot Reverse Forge works.

## Gate 7 — Visual Ambition
The result should plausibly feel on the path toward 16-bit / arcade / indie commercial quality, not a dev test board.

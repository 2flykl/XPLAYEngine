# Thumbnail Truth System

## Purpose
Ensure every feed or library tile visually tells the truth about the underlying PLX.

## Must-Haves
- readable genre
- visible action affordance
- character or key object focus
- scene depth / board structure
- visual energy

## Anti-Patterns
- mascot standing alone
- empty world plate
- abstract pattern background with a tiny figure
- same silhouette reused across multiple unrelated PLXs
- card image that could not plausibly come from play

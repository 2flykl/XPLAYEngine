# Fun Factor Gates

A PLX passes only when:
1. first input is understandable;
2. first reward arrives quickly;
3. challenge escalates gradually;
4. feedback is visible and immediate;
5. score/progress visibly changes;
6. at least one signature moment occurs;
7. a finish state exists;
8. failure is recoverable or restartable;
9. the player has a reason to replay.

Genre-specific examples:
- Runner: arcs, hazards, near-misses, chase/set-piece.
- Fighting: spacing, hit-stop, combos, special finish.
- FPS: recoil, hit feedback, waves, elite target.
- Rhythm: streaks, perfect timing, drop section.
- Puzzle: cascade, combo, board turnaround.

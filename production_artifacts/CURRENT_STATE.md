# Current State — XPLAY 3.0 Foundry Baseline

Baseline inherited from 2.9 Director Studio.

## Existing
- Vite / Phaser frontend
- Node/Express API
- Python Visual Intelligence service
- Supabase integration hooks
- Flux mascot asset library
- 10 PLX engine families
- prompt calibration
- specialist director contracts
- automated manifest audit/repair
- local + optional AI paths

## Known product challenge
The engine can technically generate multiple PLX categories but visual output has often looked assembled rather than authored:
- flat source image used as background
- imperfect subject extraction
- source objects miscast
- environment motion not always genre-correct
- weak placeholder/fallback art
- category depth uneven

## Release Locks
FPS and Fighting must remain visible and functional through every refactor.

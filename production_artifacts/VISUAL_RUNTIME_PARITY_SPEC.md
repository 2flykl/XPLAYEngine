# Visual Runtime Parity Spec

## Principle
The promotional image and the playable output must belong to the same reality.

## Parity Checks
For each PLX, compare:
- category label
- card image
- gameplay launch scene
- playable character
- environment language
- color palette
- camera framing

## Failures
A PLX fails parity if:
- card says fighting, game launches like a top-down dodge board,
- card shows city runner, game is a static shape scene,
- card promises puzzle gameplay, but no readable puzzle board exists,
- card suggests a specific cast, but runtime uses unrelated placeholders.

## Goal
Every card should feel like a freeze-frame from the game it represents.

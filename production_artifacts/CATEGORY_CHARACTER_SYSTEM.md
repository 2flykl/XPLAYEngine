# Category Character System

## Goal
Give each category a repeatable but distinct cast language.

## Rule
Do not use one mascot as the hero of everything.

## Suggested Category Starters
- FPS: tactical specialist / defender / infiltrator
- Fighting: street combat duo / rivals / dojo champion
- Runner: courier / escape artist / speed specialist
- Dodge: stealth operative / arena survivor / trap runner
- Collect: scavenger / explorer / relic hunter
- Rhythm: performer / DJ / drummer / dancer
- Puzzle: hacker / solver / engineer / tactician
- Open World: wanderer / adventurer / scout
- Racing: driver / pilot / futurist racer
- Platformer: jumper / adventurer / creature hero

## Deliverables Per Category
- default hero silhouette
- rival/enemy silhouette
- prop family
- world motif
- accent color logic
- icon/HUD motif

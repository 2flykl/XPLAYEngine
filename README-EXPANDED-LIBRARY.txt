10. Platformer
   - free horizontal movement
   - jumping
   - platforms
   - enemies
   - collectibles
   - level goal

WHY RACING + PLATFORMER?
They fill two obvious expectations that Runner does not:
- Runner is auto-forward arcade movement.
- Platformer gives full movement/exploration in a side-scrolling level.
- Racing gives vehicles/speed/track gameplay, which is a major game category testers will expect.

INSTALL
Use this package INSTEAD OF the 1.5 ZIP.

1. Stop current server: Ctrl+C
2. Copy this build over xplay-plx-engine
3. Run:
   npm install
   npm run dev

The Double Big Gulp creator/backend work from 1.5 remains included.
